# DBF Designs concept sites

Seven fictional campaign websites for Democratic and progressive clients: city council, ballot measure, mayoral movement, U.S. Senate, county party, state party and governor.

All names, committees and places are invented. Stock portrait from Pexels.

## Run it
Open `index.html`, or serve the folder: `python3 -m http.server`.

## Publish on GitHub Pages
Push to a repo, then Settings > Pages > Deploy from branch > `main` / root. All links are relative, so it works at `username.github.io/repo-name/`.

## Structure
- `index.html`: gallery
- `sites/<slug>/index.html`: one self-contained site each
- `assets/`: shared images
- `previews/`: gallery thumbnails
